# Exercise 0: Workshop Setup

Welcome to the **4-hour Hey API workshop**. This exercise verifies the project is running and sets the rule for the rest of the track: use generated contracts from the API client instead of building request, cache, or validation plumbing by hand.

## Requirements

- Confirm Node.js 20+ is installed (`node -v`).
- Run `npm install` at the project root.
- Run `npm run dev` and open the bootcamp app at `http://localhost:5173`.
- Navigate between exercises using the left sidebar.
- Toggle **Show Solution** to compare the starter and finished code.
- Click **Mark Complete** to track your progress (persisted in `localStorage`).

> Each exercise contains three files:
>
> - `exercise-N.tsx` - your starting point with `// TODO` markers
> - `solutions/exercise-N-end.tsx` - the working reference solution
> - `instructions/exercise-N.md` - this guide

## What You'll Build

Across the compressed track you will improve a **Books / Authors / Activities** dashboard backed by [`fakerestapi.vercel.app`](https://fakerestapi.vercel.app/). The focus is consistent contract-driven UI: generated reads, generated writes, generated cache identifiers, derived client-side views, and debugging mistakes that happen when teams bypass the generated layer.
